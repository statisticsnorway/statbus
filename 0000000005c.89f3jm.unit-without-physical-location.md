## Goal
A legal unit or establishment left without a physical location, for any part of its existence, shows up in the data-quality report the way a unit without a primary activity does.

## Purpose
Owner 2026-11-13 13:36: the physical location stays removable (STATBUS-611), so a unit can lose it; the report must show where that happened.

## Principle
Count it the same way as the existing cards: units that exist at the selected time frame's date, each card linking to the matching search.

## Relevant details
Today the dashboard's Data quality section has Units Missing Region and Units Missing Activity Category, each counting units that exist at the selected time frame's date (lib/unit-existence.ts) and linking to the matching search. A location's country is NOT NULL, so a unit has a physical location exactly when statistical_unit.physical_country_id is set.

## Goal
A user who edits several periods at once sees, period by period, what the save will overwrite, and saves only what they approved.

## Purpose
Ticking periods with different values used to hide what each period would lose. The owner's design (2026-11-16) keeps the change and its approval beside the period it affects.

## Principle
Physical locality: each control sits next to what it changes.

## Relevant details

## Acceptance
- [x] Ticked periods whose values differ from the form show the old value struck out and the new one beside it

- [x] Each changed period has its own Approve, cleared when that period's values change; Approve all and Tick all sit above the columns they act on

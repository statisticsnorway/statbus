## Goal
TestTypedComposeAuthorityGate in the Fast Tests livedb step type-checks the CLI packages the same way on every run.

## Purpose
Run 44406109197 (ecd2e796b) failed with 'golang.org/x/sys/unix imported as upgrade and not used' and undefined: unix in cli/cmd/install_password_terminal.go, a file unchanged since 2026-11-03. The rerun of the same SHA passed, and locally the gate passes with and without -tags livedb. A red that comes and goes on the same commit hides real failures and costs a rerun each time.

## Principle
Every failure is diagnosed; a test that reads shared build state must not depend on what ran beside it.

## Relevant details
Hypothesis: go/packages (loadTypedAuthorityPackages, GOOS=linux CGO_ENABLED=0, NeedDeps|NeedTypes) read export data for x/sys/unix that names the package 'upgrade', i.e. a build cache entry written concurrently by another livedb test package building with a different config.

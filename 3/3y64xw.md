## Goal
The installer asks for a country code from StatBus's country list and names the country; Getting started has it preselected.

## Purpose
Owner 2026-11-22: today the installer asks the country name, then the code, and Getting started asks the country again with nothing linking the two. A country StatBus does not have in its country table must not be accepted.

## Principle
The country is given once, at install, by its code; the database's country table is the list of what StatBus supports, and the installer's table stays identical to it (country_test.go already checks the seed).

## Details
Today: cli/internal/installinput/country.go validates name and code against countryTable (generated from the seed, test-checked), suggests a code from the name or domain, and only warns on a mismatch. Getting started picks settings.country_id from public.country. The code is DEPLOYMENT_SLOT_CODE (also names containers, database and subdomain). Development installs may still invent a code. Open: how the code is entered (owner unsure): type two letters, or press Enter on an empty answer to choose from a list.

## Goal
From search or reports, a user opens a map of the units the current filter selects, sized by a chosen variable.

## Purpose
Erik (Slack 2026-11-11) wants to see where the units of a search are, without leaving the search page; a CSV export plus his own map tool is the workaround today.

## Principle
The map shows the same units as the CSV export of the same filter; it reads the public API, needs no map key, and refuses a selection too large to draw.

## Relevant details
Erik's prototype: localhost:8080/statistical_units.html, branch doc/api-reference (https://github.com/statisticsnorway/statbus/pull/new/doc/api-reference): Enterprises/LU/EST toggles, Employees/Share capital/Turnover sizing, a totals box; for Morocco and Norway. His step 1: a button next to Export CSV that follows the filter, disabled above about 100 000 units with coordinates or when none have them; step 2: a map of all units in a unit's Links tree (now z2qt08's Links map). Build order (owner 2026-11-22): Regions, Links, location picker, statistical-geography design (quad-key table at several zoom levels), then this search map.

## Goal
From search or reports, a user opens a map of the units the current filter selects, sized by a chosen variable.

## Purpose
Erik (Slack 2026-11-11) built a map page on the API (statistical units, Enterprises/LU/EST toggles, Employees/Share capital/Turnover) for Morocco and Norway and proposed step 1 as a button next to Export CSV that follows the filter, disabled above about 100 000 units with coordinates or when none have them; step 2 a map of all units in a unit's Links tree.

## Principle
The map shows the same units as the CSV export of the same filter; it reads the public API, needs no map key, and refuses a selection too large to draw.

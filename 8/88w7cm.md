## Goal
An enterprise or power group made of several units can be given its own name, which replaces the derived name (the primary or controlling legal unit's) everywhere the unit appears, and is edited on its General info page. A short ticker name may sit beside it.

## Purpose
Owner 2026-11-19 20:31: a custom name for an enterprise covering several things should stick and show. Today the database already prefers short_name (16 chars) over the derived name in timeline_enterprise_def and timeline_power_group_def, but nothing in the app shows or edits it, so it is empty everywhere (Norway: 1,134,475 enterprises and 25,635 power groups, none set). The enterprise page's Name field shows the primary legal unit's name even where search would show a custom one. power_group also has an unused name varchar(256).

## Principle
One name per unit, the same on every page: a chosen name when set, else the derived one. Enterprises and power groups are not temporal, so the name is one value for all time; editing replaces it.

## Relevant details
Owner is deciding the model (2026-11-19 20:36). Candidate: name (up to 256) is the chosen name overriding the derived one; short_name is a ticker, maybe longer than 16; both editable on General info, with the derived name as the empty field's placeholder. Touches enterprise/power_group columns, timeline_enterprise_def, timeline_power_group_def, app General info pages and headers. Power group default today: the legal unit at power_level 0.

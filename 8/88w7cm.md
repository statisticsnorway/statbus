## Goal
An enterprise's optional short name is edited on its General info page and shown as its name everywhere, else the derived name.

## Purpose
Owner 2026-11-19 20:31: a custom name for an enterprise covering several things should stick and show. Today the database already prefers short_name (16 chars) over the derived name in timeline_enterprise_def and timeline_power_group_def, but nothing in the app shows or edits it, so it is empty everywhere (Norway: 1,134,475 enterprises and 25,635 power groups, none set). The enterprise page's Name field shows the primary legal unit's name even where search would show a custom one. power_group also has an unused name varchar(256).

## Principle
One name per unit, the same on every page: a chosen name when set, else the derived one. Enterprises and power groups are not temporal, so the name is one value for all time; editing replaces it.

## Relevant details
Owner 2026-11-20 08:14: minimal scope. enterprise.short_name stays varchar(16), undated (enterprise is not temporal). timeline_enterprise_def already uses COALESCE(NULLIF(short_name,''), primary LU name, primary EST name); the app must show the same on the enterprise page (header, Name) and let a user set or clear it on General info, with the derived name as the empty field's hint. Power groups: same rule, noted on g5dte8 for when their pages come. Legal unit and establishment short_name: no import carries it, nothing reads it, zero rows set on dev, ma, demo, no and the test slot; the owner considers removing them (separate ticket). History of short_name in the notes (2016 nscreg ShortName for duplicate search, cut to 16 in 3bb848ebc).

## Goal
An installation can serve its map's base tiles itself, from a PMTiles file sized to its country, instead of OpenFreeMap.

## Purpose
Owner 2026-11-22 (z2qt08 answer 2): the map starts on OpenFreeMap's public tiles (light use, no key, no SLA); serving our own tiles is a separate task because it needs storage handled intelligently. Self-hosting removes the third party at run time and lets a closed network show maps.

## Principle
One file per installation with only what its map shows: a country extract with a zoom limit, not the planet (about 120 GB). The map component names its tile style in one place, so switching source is configuration, not code.

## Details
Protomaps publishes planet PMTiles; the pmtiles CLI extracts a bounding box and max zoom into one file read by HTTP range requests, which Caddy can serve as a static file; MapLibre reads it through the pmtiles protocol. Sizes per country and zoom are to be measured (a Norway extract at a chosen max zoom). Related: z2qt08 (the map, OpenFreeMap first).

**Comment:** Every data-quality check of this installation with its integer id (h9mhxe): each rule that is not per variable once, with a fixed id (1 missing_region, 2 missing_activity_category, 3 missing_physical_location, 4 establishment_activity_differs, 7 secondary_activity_equals_primary), and each per-variable rule once per summed variable (stat_definition of type int or float), with an id from 101 up given when the variable is created and kept by the stat_definition lifecycle callback (public.quality_check_catalogue_generate / _cleanup). Part 2 of h9mhxe replaces the public.quality_check view with this table under that name.
